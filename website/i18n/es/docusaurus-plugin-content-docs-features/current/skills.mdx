# Skills para agentes de IA

El CLI es para humanos y CI. Las skills son para agentes. Once slash-commands `/straymark-*` vienen con el framework para que Claude Code, Antigravity CLI, Copilot CLI y otros puedan invocar el scaffolding de Charter, la creación de AILOG, los ciclos de auditoría, los chequeos de status y las evaluaciones de seguridad sin que tengas que dictar los pasos.

## Por qué importa

- **Los rituales que tienes que dictar son rituales que nadie ejecuta.** Un equipo que dice "acuérdate de escribir un AILOG antes de commitear" produce cero AILOGs después de la segunda semana. Las skills hacen los rituales descubribles desde dentro del agente: `/straymark-status` muestra dónde está el equipo, `/straymark-charter-new` scaffoldea el tipo de documento correcto con prompts para el alcance.
- **Una fuente de verdad para flujos manuales y de agente.** El comando del CLI `straymark new -t AILOG` y la skill `/straymark-ailog` producen el mismo documento; solo difiere el punto de entrada. Los maintainers no mantienen dos implementaciones en sync.
- **Los rituales nuevos llegan como skills nuevas.** Cuando el framework agrega un ritual nuevo (por ejemplo el ciclo de auditoría de tres skills), llega como nuevos slash commands que el agente descubre después de `straymark update-framework`. Sin reentrenamiento.

## Las once skills

| Skill | Propósito |
|---|---|
| `/straymark-status` | Status documental y chequeo de compliance |
| `/straymark-new` | Crear cualquier tipo de documento StrayMark (interactivo) |
| `/straymark-charter-new` | Scaffold de un Charter — la unidad acotada de trabajo |
| `/straymark-ailog` | Creación rápida de AILOG para el commit actual |
| `/straymark-aidec` | Registrar una decisión independiente con alternativas y trade-offs |
| `/straymark-adr` | Crear un Architecture Decision Record |
| `/straymark-mcard` | Model Card (flujo interactivo multi-paso) |
| `/straymark-sec` | Evaluación de seguridad (interactivo, consciente de OWASP ASVS) |
| `/straymark-audit-prompt CHARTER-XX` | Generar el prompt de auditoría multi-modelo |
| `/straymark-audit-execute [CHARTER-XX]` | Ejecutar una auditoría desde una CLI auditora |
| `/straymark-audit-review CHARTER-XX` | Consolidar reports de auditoría en una review calibrada |

## Cómo encajan

El agente llama a `/straymark-status` para ver qué falta. Scaffoldea un Charter con `/straymark-charter-new`, declara alcance y riesgos, entrega el trabajo, corre `/straymark-ailog` para loguear la ejecución y `/straymark-audit-prompt` para comisionar una auditoría externa. Cada skill es pequeña; la disciplina emerge de su composición.
