# Charters

Index of StrayMark Charters for this repository — the bounded units of work that pair declarative ex-ante scope with ex-post telemetry (`STRAYMARK.md §15`).

This repo self-adopts StrayMark ([`AIDEC-2026-07-13-001`](../../docs/decisions/AIDEC-2026-07-13-001-straymark-self-adoption.md)), so these Charters govern the framework's own development. Work too small for a Charter produces an AILOG instead; the two are not alternatives at the same granularity — a Charter wraps the AILOGs its execution generates.

Rows move from `## Active` to `## Closed` as part of the closing PR, not afterwards (the atomic-update convention — see any Charter's `## Charter Closure`).
